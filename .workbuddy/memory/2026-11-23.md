# 2026-11-23

## 修复附身 JumpMeow 后走路异常（MainActivity）
- 根因：重做 `Assets/Models/VRM/JumpMeow.vrm` 后，场景里 Animator 的 `m_Avatar` 覆盖丢失；Walking.fbx 是 Humanoid 动画，没有 Avatar 时不会播放，表现为「能走但没走路动作/动作错乱」。
- 同时 `viewYawBase` 被拖到了错误子骨骼，`movemeow` 用根节点 `transform.forward` 计算移动方向，导致转向后 W 仍朝旧方向走。
- 修改 `Assets/Scenes/MainActivity.unity`：恢复 Animator 的 `m_Avatar` / `m_CullingMode: 0` / `m_ApplyRootMotion: 0` 覆盖；`followTarget`、`headBone` 指向头部骨骼（1969346400），`viewYawBase` 指向 JumpMeow 根节点（1969346403）。
- 修改 `Transforming.ResolveYawBase()`：绑定状态下强制使用 `movemeow` 所在根节点作为 yaw 轴，避免重挂组件后拖错骨骼破坏移动方向。
- `movemeow.Awake()` 增加 Animator 缺 Avatar 时的警告，便于以后重做模型快速定位。
- Unity 日志确认脚本重新编译、场景重新加载，无编译错误。
